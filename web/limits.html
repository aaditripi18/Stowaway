Test the limits

The findings say where Stowaway's checks stop working. Here you check that yourself: plant random bytes in a model's weights, choose how many, how deep and how thinly spread, and see which checks catch them, from the file alone and with the unmodified model as the claimed base.

lock

Everything runs in this tab (connect-src 'none'). The payload is random bytes written with the same code path as the experiments (stowaway.embed, byte-identical in tests); nothing reads it back or runs it. You can download the planted copy and check it with the Python tool.
